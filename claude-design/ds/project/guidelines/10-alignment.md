# 對齊:三條線

整套版面站在三條垂直線上。它們 2026-09-20 在 mockup v16 定案,取代更早的 5 / 9 / 18 和 5 / 5–13 / 18。

| 線 | token | 誰站在這裡 |
| --- | --- | --- |
| **3px** | `rail-edit` | **編輯的字**:新增卡片的輸入框、詳細編輯的內容框、搜尋框、時間篩選那一排的左緣。分類色條和 📌 的左緣也是 3。 |
| **3–18px** | 溝(`gutter-width` 18) | 收合箭頭、分類色條、📌、詳細編輯鈕、塊的圖示。圖示放大到 `icon-md` 14 填滿整條溝,置中在 **10.5**。 |
| **18px** | `rail-text` | **其他所有的字**:卡片題行的第一個東西(頭像 / 空位 / 主題膠囊)、卡片內容、行事曆和設定面板的內容。 |
| **22px** | `rail-icon` | 標題列上**溝後面的第一個圖示** = 18 + 標題列的 `gap-tight` 4。 |

四種標題列(時間篩選 / 新增 / 置頂 / 清單 / 未定)都一樣。**沒有收合箭頭的表也要畫一個空的溝** ——
後面的東西才落在 22。

## 右邊也有一條線

卡片和標題列共用 `inset-right` 6px 的右內距,**所有的 ⋯ 右緣因此落在同一條線上**。
送出鈕(`submit-width` 56)的右緣也對這條線,左緣對頭像。

## 一排東西怎麼對齊

- **同一排的東西上下置中**:圓點、▾、圖示、頭像跟旁邊的字同一條中線。
- **膠囊裡的字**:固定高度 + `display:inline-flex; align-items:center; line-height:1`。
  中文字在行框裡偏上,需要時補 1–2px。
- **主題膠囊的底色從 15 開始、字從 18**(內距 2 + 1px 視覺補正):第一顆往左 `-2px`。
  **編修時的主題輸入框要用同一條規則**,不然一按編輯主題就左右跳 2px。
- **數字對齊**:所有張數(年、日、逾期、週期)在同一條橫線 —— 篩選格上排 25px 放張數、
  下排 25px 放字或圖示,箭頭跨整格高。
- **下拉的 ▾ 不能跟收合箭頭長得一樣**:分類圓點、指派人頭像的 ▾ 縮到 7px 放右上角,
  而且要在盒子**裡面** —— 凸出去的點不到。

## 色條和 📌

- **左緣同一條線 = 3**。色條平常 `rail-width` 4 寬,上下各留 8。
- **碰到卡片色線不能動**:滑過整張卡片,色條一個 px 都不動;
  **滑到色條自己**才往下讓 `pin-slot` 22px 出來給 📌,📌 淡淡出現。
- 色條算「滑到」的範圍要用 `::before` 一路含到卡片頂端,不然色條一讓位游標就脫離,會一直閃。
- 滑到時色條**只往右長**到 `rail-width-open` 9 並長出 ✓,**左緣不動** —— 按的位置不會晃。
- 色條、完成的 ✓ 條不能壓到 18px 那條線。

## flex 的坑

**flex 是「先斷行、後壓縮」**:一行差 2px 就會整塊掉到下一行,而不是把可壓縮的那塊擠小。
卡頭因此是 `nowrap`,而且**只讓日期縮**(它有省略號);指派人 `flex-shrink:0` + `max-width:96px`。
兩個一起縮的話,按比例縮的結果是名字先被壓成 0 —— 實測過。

**根容器不可以是 flex。** 每一塊都設了 `overflow:clip`,當 flex item 時自動最小尺寸掉成 0,
表格被壓成容器高度、內容被裁掉,看板「沒有東西溢出、也就捲不動」。根一律 `block`,間距用 margin。
