# 少色、圖示優先

## 顏色只有四種意義

**分類、逾期、週期、今天。** 其他一律灰階 —— 這是這套系統最容易被破壞的一條規則,
因為每個新元素都想「比較顯眼一點」。

以前指派人頭像是彩色的(一人一色),2026-09-20 拿掉:使用者說「顏色太混亂」。
現在所有頭像同一個淡灰底(`border`),使用者不能改。

| 意義 | token |
| --- | --- |
| 分類 | `category-red` … `category-grey`(使用者自己挑;自動色輪 紅 橘 黃 藍 紫) |
| 逾期 | `signal-overdue` |
| 週期 | `signal-repeat` |
| 今天 | `signal-today`;標題列上的「今日」用 `accent` |
| (完成) | `signal-done` —— 這是動作的回饋,不是分類 |

時間篩選那一排的層級色(`signal-week` 本周、`signal-month` 本月)只在那一排用。

## 跟著 Obsidian,不要寫死

程式裡**一律寫 CSS 變數**(`var(--text-muted)`),不要寫死色碼、不要自己偵測深淺。
Obsidian 切換深淺時自動跟著變,使用者換強調色也跟著變。

`tokens.json` 裡的數值是預設佈景主題在 2026-09-20 量到的解析值,**用途只有一個:畫 mockup**。
寫進程式的時候換回變數。

**`color-mix()` 要留退路**:`@supports not (…)` 的分支一定要寫,
不然舊的 Obsidian(舊 Chromium)上那個元素會完全沒有底色。

## 對比

- **淺色主題下,彩色小字要有 3:1 對比。** 主題膠囊的字在淺色下把分類色混黑到 58%
  (對比從 1.8–2.5 拉到 4.9–5.6);深色不動,那邊本來就夠。
- 一般文字 4.5:1。`tools/measure.js` 的 M12 深淺兩版都量。

## 圖示優先

- **能用圖示就不用字**,字放在 `title` / `aria-label`。標題列只放圖示(新增卡片不寫「新增卡片」)。
- **圖示已經說清楚的格子不再寫字**:逾期、週期只有圖示 + 張數。
- **頭像就好,不寫名字**(中文取最後一個字、英文取第一個字母)。
- **不能按的東西不畫圖示**。
- 只用 Lucide,**用程式裡已經有的那一顆**(`圖備()` 的名字),不要換新的。

## 說明文字

- **不寫灰色說明字**:placeholder、「點一天當開始」、「按 ↺ 還原…」這類都不要。
- 空的輸入框用淡圖示(`house` / `pen-line`),後面可以跟一個淡的「…」—— 那是記號,不是字。
- **滑過浮出的標籤不換掉、不蓋住原本的字**;說明只用 `aria-label`,不要同時有 `title`
  (Obsidian 會把 `aria-label` 畫成提示,兩個一起會互相蓋)。
