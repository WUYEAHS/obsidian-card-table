# CategoryRail

卡片左邊那條分類色條 —— 它同時是**完成鈕**,一個元素做兩件事:看得出屬於哪一區,按下去就完成。

這是整套系統裡「點」這條原則最濃縮的地方:最常用的動作(打勾)不需要先找按鈕。

## 幾何

| | 值 |
| --- | --- |
| 左緣 | `rail-edit` 3 —— 跟 📌 同一條線 |
| 寬 | `rail-width` 4;滑到時 `rail-width-open` 9 |
| 上下 | 各留 8;釘住或滑到時上面讓到 `pin-slot` 22,空出位置給 📌 |
| 圓角 | 3px |
| 顏色 | 分類色(`category-*`);完成後 `signal-done` |

## 兩條不能改的規則

**① 左緣一律 3,只往右長。** 滑過時如果左緣也跟著動,按的位置會晃(原則 11:點的位置固定)。

**② 碰到卡片色線不能動。** 滑過整張卡片,色條一個 px 都不動;**只有滑到色條自己**才往下讓位、
📌 才淡淡出現。

②有個副作用要處理:色條一往下讓 22px,游標就脫離了色條 → hover 消失 → 色條彈回去 → 又碰到游標,
會一直閃。解法是用 `::before` 把「算滑到」的範圍**一路含到卡片頂端**(平常 `inset: -8px -5px -6px -3px`,
讓位之後 `-22px`),色條讓位之後游標還在同一個範圍裡;從色條往上移到 📌 的路上也不會斷掉。

## 滑到時

- 只往右長出 ✓(7px 的 check,線寬加粗到 4)。
- 上面浮出分類名(`micro` 10px / 700,底色 `surface-alt`,陰影 `popover`)。
- **右邊的字跟著被推開**,不要蓋在字上。

## 分類色盤

七色寫死在程式裡(`標籤色`),深淺兩版一樣 —— 它們是使用者自己挑的顏色,不是佈景主題的一部分。
自動配色只輪 **紅 橘 黃 藍 紫** 五色:綠留給「完成」,灰留給沒有分類。

⚠ **分類顏色是所有看板共用、照名字記的。** 存檔只准動這次真的改到的鍵。
開發中曾經把「新增一個叫研究的分類」當成要清掉「研究」的顏色,別份看板的紫色就沒了。
刪掉前面的分類時,位置變了的分類要把原本的顏色**釘住** —— 畫面上看到什麼,存完就是什麼。
