# Card

一張任務卡片 —— 這套系統唯一的版面單位,桌機和手機一模一樣,桌機只是比較寬。

卡片直接接在標題列底下:一張一條、中間一條分隔線,**沒有外框、沒有圓角、彼此不留空隙**。
不要把每張卡片包成一個有框的盒子(那會變成「框裡還有框」)。

## 由外到內

| 位置 | 東西 | 規則 |
| --- | --- | --- |
| left `rail-edit` 3 | 分類色條 | 見 `CategoryRail`。它同時是完成鈕。 |
| left 3, top 5 | 📌 | `icon-sm` 12。釘住的一直在(`accent`);沒釘的滑到色條才淡淡出現。 |
| left `rail-text` 18 | 題行 | 頭像 → 主題膠囊 → 副標 → 日期 →(撐開)→ ✎ ⋯ |
| left 18 | 內容 | `card-body`,閱讀和編輯同一組數字。 |
| right `inset-right` 6 | ⋯ 的右緣 | 跟所有標題列的 ⋯ 同一條線。 |

內距 `card-pad-top` 7 / 右 6 / `card-pad-bottom` 8 / 左 0(左邊的 18 由格子自己補)。

## 分隔線

卡片之間是一條 `border-strong` 的 1px 線 —— 比一般框線**深一階**,從 18 畫到右邊 6,**不穿過色條那一欄**。

用 `background-image` 的線性漸層畫,**不要用 `border-bottom`**:border 會跟左邊的色條在角落斜切,
把色條吃掉一截。試過的兩種都不好:普通 1px 線跟卡片底色太接近,分不出哪裡是下一張;
6px 深色帶看起來像卡片之間破了一個洞。

## 四種狀態

| 狀態 | 怎麼畫 |
| --- | --- |
| 一般 | `surface-primary` |
| 已完成 | 整張鋪 `signal-done` 的 7%,內容 `done-dim` 0.55 淡掉、劃線。**色條不淡化** —— 手機上要看得到它可以點。留言不劃掉(留言是後來發生的事)。 |
| 已封存 | 鋪 `ink-faint` 的 12%,內容 `grayscale(1)` + `archived-dim` 0.5 |
| 剛動過 | 捲到定位後 `1.4s` 閃一下(`accent` 疊一層,慢慢亮到 18% 再退掉);定位中的那張加 `row-marker` |

閃光一定要用 `background-image`,**不要用 `background-color`** —— 會被 hover 的規則蓋掉,
滑鼠剛好停在上面就不會閃。而且只動 `opacity` / `background-image`,不動 layout,捲動中才不會掉格。

## 題行不換行

`flex-wrap: nowrap`。flex 是「先斷行、後壓縮」,差 2px 就會把 ⋯ 整顆擠到第二行,
於是有些卡片的右上角在右上、有些在左下。不准換行之後,壓縮的是日期(它有省略號);
指派人 `flex-shrink: 0` + `max-width: 96px` —— 兩個一起縮的話,名字會先被壓成 0。

## 會讓高度改變的重畫

`就地重畫`、切內容、切留言、完成編輯 **一定要**在重畫之前記 `scrollTop`,
所有高度都撐好之後才放回去。最後一張卡片是這類 bug 唯一會露餡的地方:
看板一變矮,瀏覽器就把捲動位置夾到底。

## 消費端要提供什麼

卡片本身沒有狀態 —— 它畫的是解析筆記得到的一個卡片物件。
卡片的身分是「主題 + 第一行內容」,不是 index;寫回筆記時先比位置、再比內容指紋,
全部同分而且內容不一樣就**寧可不寫**。
