# ArchiveRow

封存區清單裡的一列。也是這套系統裡「**群組內 4 / 群組間 ≥ 8**」和「**草稿要看得到結果**」
兩條規則最清楚的例子。

## 幾何

| | 值 |
| --- | --- |
| 高 | 30 |
| 字 | `list-row` 13px |
| 小圓點 | 10 × 10,`ink-faint`(有分類色就用分類色) |
| 右邊的鈕 | 24 × `control-height` 22,圓角 `radius-lg` |
| → 和 ⋯ 之間 | `gap-tight` **4** —— 它們是同一組 |

**沒有 → ⋯ 的那幾列照樣佔 52 寬**(`visibility: hidden`),張數才跟上面幾列對齊。

## 選到的樣子

`signal-today` 的 12% 當底 + `inset 0 -2px 0` 的底線 + 600 字重。
**不另外放眼睛圖示** —— 底色加底線就夠了。

一次只看一區(單選)。

## 草稿的預覽

設定面板左半按了 🗄、**還沒按 ✓** 的時候,右半多出一列**虛線的預覽**並自動選它,
底下的卡片清單只剩那一區 —— **按下去之前就看得到會搬走哪些卡片**。再按一次 🗄 收回。

虛線用 `outline: 1px dashed`(`signal-today` 的 60%)+ `outline-offset: -2px`,
字色也轉成 `signal-today`。用 outline 不用 border:不佔空間、不會把列的高度推掉。

## 可捲的清單

面板裡的清單 `max-height: 92px` 可捲,捲軸要**細、深灰、不要漸層**:
6px 寬、`scrollbar-thumb`、track 透明。顏色走變數,深淺自動跟著變。

## 寫入

分類的新增、刪除 + 搬卡片、改名,全部在**同一次原子寫入**做完,不是一次一個。
顏色鍵的搬遷在存檔時一起處理,**只准動這次真的改到的鍵**。
