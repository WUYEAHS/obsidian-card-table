# SegmentedToggle

標題列上的切換鈕,以及裝它們的「⋯ 往左彈出」。

## 幾何

| | 值 |
| --- | --- |
| 整顆切換 | `bar-height` 26 高(跟標題列一樣),圓角 `radius-full`,底色 `hover`,內距 2 |
| 裡面的鈕 | `control-height` 22 高,左右內距 9,圓角 `radius-full` |
| 字 | `chip` 11.5px;選到的加到 600 |
| 圖示 | `icon-sm` 12,跟字 `gap-tight` 4 |

選到的用 `border` 當底色。封存區選到時字轉 `signal-today`。

## 收起來、彈出來

不常用的收進 **⋯**。按 ⋯ **往左**彈出同一排,**樣子跟沒收起來時一樣**
(`.16s ease-out` 從右邊滑進來)。再按 ⋯ 或點外面收回。

⚠ **「點外面就關」要排除開它的那顆鈕** —— 不然再按一次會先被 mousedown 關掉、click 又開一個新的。

## 兩條規則

**① 選到的狀態用底色 + 底線表示就夠,不要再加一顆圖示。**
封存區以前選到時多一個眼睛圖示,拿掉了。

**② 單選就是單選。** 未完成 / 已完成二選一;封存區一次只看一區。

## 桌機和手機的差別

只有一個:**未完成 / 已完成 / 含封存在桌機是篩選列最右邊那一格**(使用者明講桌機不要收),
**手機收在時間篩選標題列的 ⋯ 裡**。「全部」桌機在年份左邊,手機也收在同一個 ⋯ 的最上面。

這是**排法**的差別(看 `this.密`),不是兩套版面。
