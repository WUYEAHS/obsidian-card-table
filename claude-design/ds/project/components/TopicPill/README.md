# TopicPill

卡片題行上的三個小東西:**主題膠囊、副標、指派人頭像**。它們決定了 18 那條線上每張卡片長得齊不齊。

## 主題膠囊

分類色的淡底 + 分類色的字。尺寸是使用者自己在 mockup 上調出來的,**所有膠囊一起改**:

| | 值 |
| --- | --- |
| 高 | `pill-height` 17 |
| 圓角 | `radius-pill` 8 |
| 左右內距 | 2 |
| 字 | `card-topic` 12.8px / 700 / line-height 1 |

**底色從 15 開始、字從 18**(內距 2 + 1px 視覺補正):第一顆往左 `-2px`。
編修時的主題輸入框要用**同一條**規則,不然一按編輯主題就左右跳 2px(原則 10)。

字上下置中靠 `inline-flex` + `align-items:center` + `line-height:1`,不是靠 padding。

### 長度上限

新打的主題最多 **6 個中文字寬**(英文 12 個字母),超過就截掉並跳一次提示。
**舊筆記裡比較長的主題照讀、一個字都不改** —— 在讀的路徑上截會換掉卡片的身分;
畫面上用省略號補,全名放 `aria-label`。

### 對比

深色下字就是分類色。**淺色下把分類色混黑到 58%**,對比從 1.8–2.5 拉到 4.9–5.6(R5)。
`color-mix` 要留 `@supports not` 的退路。

## 副標

**只有第一個 `#` 是主題**,第二個以後是副標:`card-subtitle` 12.8px / 500、內文色、
**沒有底色、沒有膠囊**。一排彩色膠囊會讓「顏色只有四種意義」這條規則破功。

## 指派人頭像

`avatar` 17(跟膠囊等高),圓形,底色 `border`、字 `micro` 10px / 700。
頭像 = 名字的第一個字:中文取最後一個字、英文取第一個字母。**不寫名字。**

**所有指派人同一個淡灰底,使用者不能改。** 以前一人一色,2026-09-20 拿掉 ——
顏色只留給分類、逾期、週期、今天。

**沒有指派人也要留一個 17 寬的空位**,主題才跟別張卡片對齊;滑過卡片時那個空位淡淡浮出一個 ＋
(`ink-faint`,桌機 0.6、手機常駐 0.35)。

## 順序

題行從 18 開始,固定是:**頭像 / 空位 → 主題膠囊 → 副標 → 日期**,然後撐開,右邊是 ✎ ⋯。
位置由 DOM 建立的順序決定,**不要用 CSS 的 `order` 排**。
