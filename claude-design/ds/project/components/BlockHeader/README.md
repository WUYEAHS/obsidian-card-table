# BlockHeader

每一塊上面那條 26px 的標題列。時間篩選、新增卡片、置頂表、清單表、未定區**共用同一條**——
新的可收合塊也要接它,不要再手刻一份。

## 幾何

| | 值 |
| --- | --- |
| 高 | `bar-height` 26 —— **手機和桌機一樣**,不要讓裡面的東西決定高度 |
| 左邊 | 溝 3–18(`gutter-width` 18),圖示放大到 `icon-md` 14 填滿,置中在 10.5 |
| 溝後面第一個東西 | `rail-icon` 22 = 18 + `gap-tight` 4 |
| 右內距 | `inset-right` 6 —— ⋯ 的右緣因此跟卡片的 ⋯ 同一條線 |
| 裡面的鈕 | `control-height` 22 高;⋯ 是 `more-button-w` 26 × 22,**沒有左右內距** |

**沒有收合箭頭的表也要畫一個空的溝**,後面的東西才落在 22。

## 裡面放什麼

從左到右:**溝(收合箭頭)→ 圖示 → 標題字 → 張數 →(撐開)→ 右邊的鈕 → ⋯**

- **只放圖示,不放字。** 說明放 `aria-label`(不要同時有 `title`:Obsidian 會把 `aria-label`
  畫成提示,兩個一起會互相蓋住)。
- 時間篩選的標題列固定寫「今日 09-20(日)」(點了回到今天,字色 `accent`),
  收起來**不寫**篩選摘要 —— 清單表的標題列已經寫了,不要重複。
- 張數用 `count` 11px、灰、`tabular-nums`,只寫數字。
- 「全部」是**字**不是圖示,所以要有框才看得出可以按(`ct-bar-btn--framed`)。

## 標題列的圖示對照

| 塊 | Lucide |
| --- | --- |
| 時間篩選 | `calendar-days` |
| 新增卡片 | `square-pen` |
| 分類與指派人設定 | `settings` |
| 行事曆 | `calendar-days` |
| 置頂 | `pin` |

新增卡片那一塊有四種內容(新增 / 詳細編輯 / 設定 / 行事曆),**標題列的圖示跟著換**。

## 字要補正

`block-title` 12px / 700,行高 **1.4** + 上面補 **2px**。
中文字在行框裡偏上,用 `line-height:1` 壓、再配 `overflow:hidden`,會把字的上緣裁掉。

## 收合

一律走同一個滑動:**收** = 先滑到只剩標題列再重畫(收合狀態那時候才存);
**展** = 先重畫,新的塊從「只有標題列」的高度滑開。

- 動畫中再按一次不理它,不然舊的塊還在滑、狀態已經被翻兩次。
- 系統要求減少動態(`prefers-reduced-motion`)就直接重畫。
- 收合狀態記在**這台裝置**,不進筆記。

## 塊本身

圓角 `radius-block` 9、1px `border`、底色 `surface-secondary`(控制區)或 `surface-primary`(卡片表),
陰影 `block`。**`overflow: clip` 兩個方向** —— 只 clip 橫向的話圓角裁不到東西,標題列的深色底和
表格最後一列的底色會從圓角露出來。

可以放心 clip,因為**所有浮出來的東西(色盤、日期、選單、面板)都掛在 `document.body`**。
新加的浮動面板也要掛那裡。
