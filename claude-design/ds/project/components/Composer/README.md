# Composer

新增卡片那一塊。它有**四種內容**共用同一個外殼:新增 / 詳細編輯 / 分類與指派人設定 / 行事曆。
標題列的圖示跟著換(`square-pen` / `maximize-2` / `settings` / `calendar-days`)。

換內容時**只換這一塊**,時間篩選一直留著;而且一律有動畫:
量舊高度 → 畫新內容 → 高度滑到新的 + 新內容從旁邊淡入(去設定、行事曆從右,回來從左)。
平常的重畫不動。

## 輸入框:透明、沒有框

這是這套系統最違反直覺、但使用者明確要的一條:**編輯欄位沒有底色、沒有框線**,
字從 `rail-edit` **3** 開始 —— 看起來直接打在塊上。

- 高度 `bar-height` 26(跟送出鈕一樣高)。以前 44:空的時候中間空一大塊、送出鈕孤零零掛在右下角。
- 內容長了編輯器自己會長高。
- 詳細編輯的內容框 `min-height: 128px`。
- **沒有欄位標籤、沒有框和框之間的直線。**

空白時用**圖示**不用 placeholder:主題 `house`、內容 `pen-line`,12px、`ink-faint`,
放在游標右邊一點(游標在 3,圖示從 7 開始)。後面跟一個淡的「…」讓人知道這裡可以打字 ——
那是記號,不是字。

## 送出鈕

| | 值 |
| --- | --- |
| 尺寸 | `submit-width` **56** × `bar-height` 26 |
| 圓角 | `radius-pill` 8 |
| 底色 | `accent-interactive`(R4:**一律**,不跟指派人或分類變色) |
| 圖示 | `send-horizontal`,`on-accent` |

**左緣對頭像、右緣對標題列的 ⋯**(使用者在 mockup 上自己畫了兩條線)。
**固定大小,不跟著輸入框長高。** 詳細編輯模式裡送出鈕自己一排、靠右,不跟內容框同一行。

## 標題列上的東西

**分類圓點** `dot` 16、點擊範圍 `dot-hit` 26 × 26,`▾` 縮到 7px 放右上角
(不會跟收合箭頭搞混)。圓點**靠左不置中** —— 它是溝後面的第一個東西,要落在 22 那條線上;
`▾` 一定要在盒子**裡面**,凸出去的點不到,check4 也會報溢出。

**常用主題**接在後面:一行,放不下的整顆藏起來,「☰ 更多」永遠在最前面,
後面的數字是張數的層級(11px、灰、不粗)。右邊一個小箭頭收合這一排 ——
**沒有底色也沒有框**,狀態靠方向(收起 ⌄ / 展開 ›)。

**編輯時的主題框不要拉長**:寬度跟著字走(≈ ch),空的時候只有一小格,上限 6 個中文字。
不要用 flex 撐、不要給 `min-width`。

## 送出鍵

**只有一個判斷。** 新增卡片、編輯內容、寫留言、改留言全部走同一個函式,
不要再各自寫 `e.shiftKey` / `!e.shiftKey`(1.4.6 以前留言跟其他地方是反的)。
Enter 還是 Ctrl+Enter 由設定決定。

⚠ 送出鍵和 Esc 要在**視窗的捕獲階段**攔 —— Obsidian 的 Ctrl+Enter 預設是「切換勾選框」,
在容器上攔會被它搶走。

## 編輯器

正常情況下是 **Obsidian 自己的即時預覽編輯器**(非公開 API 取得的類別),
拿不到就退回 `textarea` —— **退路一定要留著**。

重畫、收掉編修、關閉分頁都要把編輯器**卸掉**(它掛在外掛底下,DOM 拿掉還活著)。
