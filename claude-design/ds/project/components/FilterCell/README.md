# FilterCell

時間篩選那一排的格子。**時間是主軸**,所以這是看板上最上面、最常按的一排。

排列固定:`[(全部) 年][本月 / 本周][本日]`,接著 `[已逾期][週期]`。

## 幾何

| | 值 |
| --- | --- |
| 整排左緣 | `rail-edit` 3(跟編輯的字同一條線) |
| 格子之間 | `gap-row` 6;月 / 週兩格之間 2 |
| 年 / 月 / 週 / 日 | `filter-cell-w` **116** 寬 |
| 已逾期 / 週期 | `filter-cell-small` **52** 寬 |
| 單排 | `filter-cell-h` 25 高 |
| 兩排 | `filter-cell-tall` 52 高 = 25 + 2 的縫 + 25 |
| 圓角 | `radius-block` 9 |

116 是量出來的:最長的標籤「11/23 – 11/29」放得下、不用縮字。
**同一種格子一樣寬** —— 不要為了省空間讓四格各長各的。

## 上下兩排

- **上排 25:張數**,`count` 11px、`tabular-nums`。所有格子的張數因此落在同一條橫線上。
- **下排 25:字或圖示**,`filter-label` 12.5px / 600 / `line-height:1`。
- **箭頭跨整格高**(不在這個兩排的盒子裡),才會跟本日那一格的箭頭齊平。
- 沒有張數的格子(月 / 週)只有一排,那一排置中。

月 / 週不寫張數。張數都是灰的,只有**逾期(紅)**和**週期(紫)**有顏色。

## 選到的樣子

**格子本身不上色。** 選到的那格亮一點:`accent-interactive` 的 24% 當底、65% 當 1px 內框線。
箭頭的顏色轉成 `accent`。

## 一個游標

四格都從**同一個游標日期**推出來,箭頭一律是「移游標(層, 步)」:
換年 → 1/1、換月 → 1 號、換週 → 那一週第一天、換日 → 前後一天。

**不要再加回每一格自己的偏移** —— 那會讓四格各走各的,正是這個設計要解決的事。

已選著的格子**再點一次 = 回到今天**;不另外放「今天」「明天」「不排」這種鈕。

## 字距和標籤

- 數字和括號、連字號之間要留空:`9/19 (六)`、`9/14 – 9/20`。
- **週的標籤兩邊都寫月份**(`9/14–9/20`),不要省略;跨年時年份交給年格(寫 `26–27`)。
- 區間用波浪號、不寫星期(`09-17 ~ 10-18`);單日有星期(`09-19(六)`)。
- 年份加字距時用 padding 補回來,保持置中。
- 標籤放不下時,整排畫完之後統一縮字,**不出省略號**。

## 圖示

逾期 `clock-alert`、週期 `refresh-ccw-dot`。**圖示已經說清楚的格子不再寫字** ——
這兩格只有圖示 + 張數。

## 窄的時候

視窗或分頁變窄(≤700 或分頁 < 560)時,格子照比例縮:`flex: 1 1 0`、字小一號。
這是排法的切換,由 JS 判斷一次掛 class,**不寫 media query**。
