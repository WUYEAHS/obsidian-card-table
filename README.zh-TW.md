# Card Table - Dated Tasks 卡片看板：任務分類日誌

**以任務為導向的卡片日誌看板。** 每一件事就是一張卡片,卡片排成一張表格 —— 時間篩選一鍵看今天、本週、本月,打字就能搜主題和內容,分類標出任務的狀態,好幾個人也能在同一張看板上協作。

同一張看板有兩種用法,照你的習慣切換:

- **表格模式** —— 一列一張卡片,掃一眼就知道現在要做什麼。
- **沉浸模式**(1.7 推出)—— 點開一張卡片全版閱讀,再按編輯就像在寫一篇單獨的日誌。

1.6.1 起,卡片用 [Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) 和 [Dataview](https://github.com/blacksmithgu/obsidian-dataview) 外掛同一種 `[欄位:: 值]` 寫法,它們的查詢也看得到卡片的日期和循環。

- **時間篩選。** 年、月、週、日、已逾期、週期永遠在畫面上,四格跟著同一個日期連動。不用挑日期、不跳對話框,◀ ▶ 按幾下就到任何一天。
- **快速搜查。** 在新增卡片打主題或內容,表格就跟著篩選。
- **任務分類。** 分類就是顏色,也是狀態 —— 紅色那一區叫「等回復」,裡面的卡片就都在等回復。
- **多人協作。** 每張卡片都能留下有署名、有時間的留言;每一次寫入都是原子的,兩台裝置同步也不會互相蓋掉。
- **它還是純文字。** 日期、指派人、置頂、留言、循環全寫在筆記裡。外掛關掉之後,仍然是一份誰都看得懂的待辦清單。

## 安裝

1. 設定 → 社群外掛 → 開啟社群外掛。
2. 瀏覽 → 搜尋 **Card Table - Dated Tasks**(卡片看板：任務分類日誌)→ 安裝並啟用。

還沒上架的話:從 [最新版本](../../releases/latest) 下載 `main.js`、`manifest.json`、`styles.css`,
放進 `<你的 vault>/.obsidian/plugins/card-table/`,重新載入 Obsidian 再啟用 **卡片看板：任務分類日誌**。

## 開始使用

1. 打開一篇筆記,從指令面板、左側欄的圖示或分頁的 `⋯` 選 **用卡片看板開啟**。
   每篇筆記會記住你上次用哪一種模式,下次照舊開。
   還沒用看板開過的筆記,按左側欄的圖示會先問你:把這份筆記開成卡片看板,或開一份新檔案。
2. 全新的筆記會自動建好五個分類(`## 1` … `## 5`),分類在看板上用顏色表示。
3. 在 **新增卡片** 打主題和內容,按 `Shift + Enter` 送出。
   卡片會放在上方篩選列目前顯示的那一天、那一週或那個月。
4. 點圓圈標成完成、點日期改日期、✎ 編輯、💬 留言。

## 功能

### 時間篩選
- **四格連動** —— 年、月、週、日跟著同一個日期走,動其中一格,其他格一起跟上。
- **已逾期與週期** —— 就在日期格旁邊,一點就到。
- **行事曆** —— 格子不夠用時挑一天或一段;一週可以從週一、週日、今天或每月 1 號起算。

### 搜尋
- **打字就篩選** —— 新增卡片的主題和內容框,就是表格的篩選。
- **常用主題** —— 一點就帶入;用過的主題會帶回它上一次的分類。

### 卡片
- **就地編輯** —— 卡片裡就是 Obsidian 的即時預覽編輯器,邊打邊存;內容裡的待辦可以直接勾。
- **置頂、循環、封存** —— 置頂表在最上面,`[repeat:: every 2 weeks]` 循環,先封存才刪除。
- **融合與輸出** —— 好幾張合成一張,或把目前的篩選輸出成 PNG、PDF。

### 分類
- **顏色就是狀態** —— 紅色那一區叫「等回復」,裡面的卡片就都在等回復。
- **就地管理** —— 在新增卡片的「⋯」裡改名、換色、新增、刪除分類。

### 多人協作
- **留言** —— 有署名、有時間,跟著它說的那張卡片。
- **指派人或個人使用** —— 把卡片指派給人,或整個關掉指派人。
- **同步也安全** —— 每一次寫入都是原子的,兩台裝置不會互相蓋掉。

### 手機與版面
- **真正的手機版面** —— 是卡片,不是硬縮小的表格。
- **窄版或寬版**(桌機);深色、淺色跟著 Obsidian 的佈景主題。

### 純文字
- **Tasks、Dataview 讀得懂的欄位** —— `[due:: …]`、`[start:: …]`、`[repeat:: …]`;舊筆記照樣讀得懂。
- **繁體中文與英文介面。**

## 鍵盤

格式快捷鍵**用你自己的設定**:編輯卡片時用的就是 設定 → 快捷鍵 裡綁的那些,跟在一般筆記裡打字一模一樣 —— 卡片的編輯框就是 Obsidian 的編輯器,有即時預覽、復原和 `[[` 建議。

| Obsidian 指令 | 插入 |
| --- | --- |
| Toggle bold | `**文字**` |
| Toggle italic | `*文字*` |
| Toggle highlight | `==文字==` |
| Toggle code | `` `文字` `` |
| Toggle strikethrough | `~~文字~~` |
| Add internal link | `[[文字]]` |
| Insert Markdown link | `[文字]()` |

送出鍵在新增卡片、編輯內容、留言都是同一套:

| 按鍵 | 預設 | 設定成「Enter 送出」 |
| --- | --- | --- |
| `Enter` | 換行 | 送出 |
| `Shift + Enter` | 送出 | 換行 |
| `Ctrl + Enter` / `⌘ + Enter` | 送出 | 送出 |
| `Esc` | 結束編輯 | 結束編輯 |

## 設定

分類跟外掛裡的設定頁一樣;最上面的 **更新內容** 可以看每一版加了什麼。

| 分類 | 可以設定 |
| --- | --- |
| 一般 | 語言、這台電腦是誰在用、個人使用 |
| 時間篩選 | 打開時先看哪一段、一週怎麼算、「全部」格 |
| 卡片外觀 | 版面寬度、已完成的長相、分類名稱、最後編輯時間、留言與留言位置 |
| 新增與編輯 | 送出鍵(見 [鍵盤](#鍵盤))、編輯時游標和卡片的位置、完成時取消置頂 |
| 動作完成後要不要跳轉 | 每一種動作要不要捲到那張卡片 |
| 筆記格式 | 把舊卡片全部轉成新格式(會先備份) |

## 文字格式

這就是全部的儲存格式 —— 看板上看到的東西,全都來自像這樣的幾行字:

```markdown
## 1

- [ ] [pin:: on] [訂貨] [start:: 2026-09-11] [due:: 2026-09-14] #欣明
	每樣兩箱,週五前要到
	- [ ] 打給廠商
	[cm:: 2026-09-11 14:20|欣明] 報價回來了,比上次漲 8%
	[ed:: 2026-09-11 14:20]

- [x] [巡田] [due:: 2026-09-08] [repeat:: every 2 weeks]
	再看一次疑似黃龍病那棵
	[done:: 2026-08-25]
	[ed:: 2026-09-08 08:30]
```

第一行是卡片本身:置頂、主題、日期、循環、指派人。底下依序是內容(照你打的寫,不會自動加項目符號)、循環的完成記錄、留言,最後一行是編輯時間。外掛自己寫的這幾行也沒有符號。

| 筆記裡寫 | 意思 |
| --- | --- |
| `- [ ]` / `- [x]` | 一張卡片,未完成 / 已完成 |
| `[pin:: on]` | 置頂 |
| `[主題]` | 卡片的主題 |
| `[due:: 2026-09-11]` | 日期。一段區間寫成 `[start:: 2026-09-11] [due:: 2026-09-14]` |
| `[repeat:: every 2 weeks]` | 每兩週一次。`every 3 days`、`every month` 都可以 |
| `#欣明` | 指派人(要在指派人名單裡) |
| 內容行 | 一行一項;符號可有可無(`- `、`* `、`1. `)。`- [ ]` 會顯示成可以勾的待辦 |
| `[done:: 2026-08-25]` | 只有循環卡片會寫:那一次按了「本次完成」(一般卡片看第一行的勾就好) |
| `[cm:: 2026-09-11 14:20\|欣明] 內容` | 一則留言 |
| `[ed:: 2026-09-11 14:20]` | 最後編輯時間,永遠是卡片的最後一行 —— 外掛自動寫的 |
| `## Archive` | 封存區 |

第一行上的其他欄位(例如 Tasks 寫的 `[completion:: …]`、`[priority:: …]`)會原樣留著。

**舊寫法照讀,改到才換。** 1.6.0 以前寫的 `＠{2026-09-11 ~ 2026-09-14}`、`✎{…}`、`📌`、`🔁 every 2 weeks`(和 `🔁 每2週`)、`💬{…}`、內容前的 `．` 都繼續認得;
哪張卡片被編輯、打勾或改日期,那張才換成新寫法,其他卡片一個字都不動。
想一次全部換掉,用設定裡的 **把舊寫法全部轉成新格式**(每份筆記會先備份)。
1.6.0 以前的卡片看板讀不懂新寫法,開這些筆記的每台裝置都要更新。`#long-term` 1.5 起沒有特別意思,留在筆記裡當一般標籤。

## 卡片看板、Tasks 和 Kanban

**Tasks 和 Dataview。** 卡片看板寫的 `due`、`start`、`repeat`,就是 [Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) 外掛在 Dataview 格式裡讀的欄位;所有 `[欄位:: 值]` 也都查得到([Dataview](https://github.com/blacksmithgu/obsidian-dataview))。循環由卡片看板自己處理(本次完成),循環卡片請在卡片看板裡打勾。

**Kanban。** 卡片看板的靈感來自 **[Kanban](https://github.com/mgmeyers/obsidian-kanban) 外掛的表格模式(table view)** —— 同樣的 Markdown 清單,不排成一欄一欄,而是一列一列讀。從那裡出發,再長成一個以日期和留言為主軸的看板。

| | Kanban | 卡片看板 |
| --- | --- | --- |
| 以什麼為主軸 | 階段 —— 這張卡片在哪一欄? | 時間 —— 今天、本週、本月要做什麼? |
| 移動卡片 | 拖到另一欄 | 改日期、打勾、封存 |
| 每天打開看到的 | 整個看板 | 一鍵看今天(或任何一天、一週、一個月) |
| 對話 | — | 每張卡片有署名、有時間的留言 |
| 多人 | — | 就是為這個設計的:每台裝置自己的身分、原子寫入 |
| 手機 | — | 專屬的窄版版面 |

**可以兩個一起裝嗎?** 可以。卡片看板只接管你用它開過的筆記(每篇筆記各自記住),不會自己把 Kanban 看板換成卡片看板,停用或重新載入時也不會拆掉 Kanban 的攔截。
兩個外掛讀的都是 `## 標題` 和 `- [ ]` 卡片,所以卡片看板的筆記也能用 Kanban 開;不過 Kanban 只認得它自己的 `@{日期}`,卡片看板的 `[due:: …]` 在 Kanban 裡會顯示成一般文字。

## 設計原則

1. **每一次寫入都是一次原子的讀改寫**(`Vault.process`),同步、別的分頁、上一個動作同時寫入時,不會被舊內容蓋掉。
2. **看板從不把自己那份寫回檔案。** 所有改動都經過同一個寫入者。
3. **卡片的身分是它的主題加第一行內容。** 兩張一樣的時候,先看它在分類裡是第幾張(再用整行和內容確認),接著才比內容、整行原文和編輯時戳;都分不出來就寧可不寫,不用猜的。
4. **一次只動最少的行。** 打勾只改那一行和編輯時間,不會整份重寫。
