# Card Table 卡片日誌

**把任何一篇 Markdown 筆記變成一張照日期排的任務卡片表 —— 點一下就看今天、本週或本月,每張卡片上都能直接留言。**

- **日期優先。** 最上面那一排篩選永遠在畫面上:年、本日、本周、本月、已逾期、長期。不用挑日期、不跳對話框 —— 點一下就篩好,◀ ▶ 往前往後翻一天。
- **每張卡片都能對話。** 留言會記下誰、什麼時候留的,一張卡片就是一小段日誌。好幾個人可以同時用同一篇筆記協作。
- **它還是一篇筆記。** 日期、指派人、置頂、留言、循環全都是純文字。外掛關掉之後,那篇筆記仍然是一份誰都看得懂的待辦清單。

覺得好用的話,可以 [在 Ko-fi 請作者喝杯咖啡](https://ko-fi.com/jiajiunwu)。

## 安裝

1. 設定 → 社群外掛 → 開啟社群外掛。
2. 瀏覽 → 搜尋 **Card Table** → 安裝並啟用。

還沒上架的話:從 [最新版本](../../releases/latest) 下載 `main.js`、`manifest.json`、`styles.css`,
放進 `<你的 vault>/.obsidian/plugins/card-table/`,重新載入 Obsidian 再啟用 **Card Table**。

## 開始使用

1. 打開一篇筆記,從指令面板、左側欄的圖示或分頁的 `⋯` 選 **用卡片日誌開啟**。
   每篇筆記會記住你上次用哪一種模式,下次照舊開。
   還沒用看板開過的筆記,按左側欄的圖示會先問你:把這份筆記開成卡片日誌,或開一份新檔案。
2. 全新的筆記會自動建好五個分類(`## 1` … `## 5`),分類在看板上用顏色表示。
3. 在 **新增卡片** 打主題和內容,按 `Shift + Enter` 送出。
   卡片會放在上方篩選列目前顯示的那一天、那一週或那個月。
4. 點圓圈標成完成、點日期改日期、✎ 編輯、💬 留言。

## 功能

### 用時間篩選

- **一鍵篩選** —— 年份、本月 / 本周、本日就在篩選列的第一塊,◀ ▶ 往前往後翻;本日底下會顯示星期幾。
- **年份跟著走** —— 年份那一格永遠顯示「現在在哪一年」,本周或本月翻到隔年會自動跟著變。點年份回到今年。
- **已逾期、週期** —— 同一格上下各半。設定裡打開「全部」,年份左邊會多一格全部。
- **本周照你的習慣算** —— 照週曆,或從今天起算七天(這週前幾天已逾期的卡片就不會混進來)。
- **顯示 未完成 / 已完成 / 含封存** —— 三個開關,清單、數字、行事曆一起套用。視窗太窄時收成一顆 `⋯`。
- **行事曆** —— 點一天,或點兩天選一段。每次打開都從這個月開始。
- **不用搜尋框的搜尋** —— 「新增卡片」的主題和內容框,打字就會篩選。

### 卡片

- **置頂表** —— 置頂的卡片獨立一張可收合的表,放在最上面,不受日期篩選影響。
- **常用主題** —— 最常用的主題一點就帶入。每天都用的可以釘選,永遠排在最前面。每份筆記各自有自己的釘選。
- **就地編輯** —— 主題和內容一次改,邊打邊存。游標可以設定停在最前面或最後面。
- **分類就是顏色** —— 分類旁邊的 `⋯` 可以換顏色,也可以直接改名(會改筆記裡的 `## 標題`)。打開「顯示分類名稱」,每張卡片都寫出它在哪一區。
- **分類就是狀態** —— 把分類取名成一種狀態,例如紅色那一區叫「等回復」,打開「顯示分類名稱」,那一區的卡片就都寫著等回復(電腦版在完成圓點上方,手機版在主題後面)。點名字就能換到別的分類;卡片完成之後改顯示「已完成」。也可以設定打勾完成時順便取消置頂。
- **指派人,或個人使用** —— 把卡片指派給名單上的人;只有自己用的話打開「個人使用」,指派人欄位就收起來。
- **循環卡片** —— `🔁 every 2 weeks`。按「本次完成」會把日期推到下一次,並留一條記錄。
- **先封存、再刪除** —— 封存會把卡片搬到 `## Archive`,封存之後才能刪除。
- **融合** 好幾張成一張,**輸出** 目前篩選的卡片成長圖 PNG 或列印成 PDF。

### 留言與多人協作

- **有署名、有時間的留言** —— 每台裝置記得「這台是誰在用」(只存在那台裝置,不會同步)。
- **讓日誌更豐富** —— 留言跟著它說的那張卡片,一張卡片就收齊整件事:任務本身、後續、回覆。
- **為多人使用而做** —— 每一次寫入都是原子的讀改寫,兩台裝置同步同一篇筆記不會互相蓋掉。第一行一模一樣的卡片也分得出來。
- 留言可以放在內容上面或下面,也可以整個關掉。

### 手機與窄螢幕

- 手機和窄分頁有專屬的卡片版面,不是把表格硬擠小。
- 日期箭頭和卡片按鈕都放大到手指點得到;底部浮動導覽列不會蓋住最後一張卡片。
- 桌機可以選窄版(跟筆記的可讀行寬一樣)或寬版。

### 語言

- 英文與繁體中文。跟著 Obsidian 的語言,也可以在設定裡指定。

## 鍵盤

格式快捷鍵**用你自己的設定**:編輯卡片時用的就是 設定 → 快捷鍵 裡綁的那些,跟在一般筆記裡打字一模一樣。

| Obsidian 指令 | 插入 |
| --- | --- |
| Toggle bold | `**文字**` |
| Toggle italic | `*文字*` |
| Toggle highlight | `==文字==` |
| Toggle code | `` `文字` `` |
| Toggle strikethrough | `~~文字~~` |
| Add internal link | `[[文字]]` |
| Insert Markdown link | `[文字]()` |

送出鍵在新增卡片、編輯內容、留言都是同一套:

| 按鍵 | 預設 | 設定成「Enter 送出」 |
| --- | --- | --- |
| `Enter` | 換行 | 送出 |
| `Shift + Enter` | 送出 | 換行 |
| `Ctrl + Enter` / `⌘ + Enter` | 送出 | 送出 |
| `Esc` | 結束編輯 | 結束編輯 |

## 設定

| 設定 | 作用 |
| --- | --- |
| 個人使用 | 全部不顯示指派人 |
| 打開看板時先看哪一段 | 預設的篩選範圍 |
| 語言 | 跟著 Obsidian、English 或繁體中文 |
| 版面寬度 | 窄版(像可讀行寬)或寬版 |
| 留言 | 要不要用留言、放在內容上面或下面 |
| 項目符號 | 內容每一行前面自動加「．」 |
| 送出鍵 | 見 [鍵盤](#鍵盤) |
| 一週從哪天開始 | 週一或週日 |
| 動作完成後要不要跳轉 | 每一種各自設定:移回未完成、標成完成、封存、置頂、設為今日、新增 |
| 按下編輯之後卡片停在哪裡 | 原地不動、拉到最上面、交給瀏覽器 |
| 按下編輯之後游標在哪裡 | 最前面(預設)或最後面 |
| 「本周」怎麼算 | 照週曆,或今天起七天 |
| 時間篩選顯示「全部」 | 年份左邊多一格全部(預設不顯示) |
| 顯示分類名稱 | 每張卡片寫出所在的分類標題,當成狀態看 |
| 完成時自動取消置頂 | 預設關 |

## 文字格式

這就是全部的儲存格式 —— 看板上看到的東西,全都來自像這樣的幾行字:

```markdown
## 1

- [ ] [訂貨] ．每樣兩箱,週五前要到 ＠{2026-09-11} #欣明 📌 ✎{2026-09-10 09:12}
	．打給廠商了,等報價
	．💬{2026-09-11 14:20|欣明} 報價回來了,比上次漲 8%

- [x] [巡田] ．再看一次疑似黃龍病那棵 ＠{2026-09-08}
```

| 筆記裡寫 | 意思 |
| --- | --- |
| `- [ ]` / `- [x]` | 一張卡片,未完成 / 已完成 |
| `[主題]` | 卡片的主題 || `＠{2026-09-11}` | 日期。`＠{2026-09-11 ~ 2026-09-14}` 是一段區間 |
| `#欣明` | 指派人(要在指派人名單裡) |
| `📌` | 置頂 |
| `✎{2026-09-11 14:20}` | 最後編輯時間,到分鐘 —— 外掛自動寫的(舊的帶秒數照讀) |
| `💬{2026-09-11 14:20\|欣明} 內容` | 一則留言 |
| `🔁 every 2 weeks` | 每兩週一次。`every 3 days`、`every month`,以及舊的 `🔁 每2週` 都可以 |
| `#long-term` | 1.5 起沒有特別意思(以前代表長期),留在筆記裡當一般標籤 |
| `．` | 內容行前面的項目符號,可以不寫 |
| `## Archive` | 封存區 |

卡片底下縮排的行就是它的內容。

## Card Table 和 Kanban

Card Table 的靈感來自 **[Kanban](https://github.com/mgmeyers/obsidian-kanban) 外掛的表格模式(table view)** —— 同樣的 Markdown 清單,不排成一欄一欄,而是一列一列讀。從那裡出發,再長成一個以日期和留言為主軸的看板。

兩個外掛讀的都是由 `## 標題` 和 `- [ ]` 卡片組成的 Markdown 筆記,但它們回答的是不同的問題。

| | Kanban | Card Table |
| --- | --- | --- |
| 以什麼為主軸 | 階段 —— 這張卡片在哪一欄? | 時間 —— 今天、本週、本月要做什麼? |
| 移動卡片 | 拖到另一欄 | 改日期、打勾、封存 |
| 每天打開看到的 | 整個看板 | 一鍵看今天(或任何一天、一週、一個月) |
| 對話 | — | 每張卡片有署名、有時間的留言 |
| 多人 | — | 就是為這個設計的:每台裝置自己的身分、原子寫入 |
| 手機 | — | 專屬的窄版版面 |

**可以兩個一起裝嗎?** 可以。Card Table 只接管你用它開過的筆記(每篇筆記各自記住),
不會自己把 Kanban 看板換成 Card Table。1.4.7 起,就算 Kanban 這類外掛也攔截了同一個 Obsidian 方法,
Card Table 停用或重新載入時也不會把對方的攔截一起拆掉。
不過一篇筆記最好只用其中一個:Card Table 編輯過的筆記會寫進自己的標記(例如 `✎{…}`)。

## 設計原則

1. **每一次寫入都是一次原子的讀改寫**(`Vault.process`),同步、別的分頁、上一個動作同時寫入時,不會被舊內容蓋掉。
2. **看板從不把自己那份寫回檔案。** 所有改動都經過同一個寫入者。
3. **卡片的身分是它的第一行。** 第一行一樣的時候,先看它在分類裡是第幾張(再用整行和內容確認),接著才比內容、整行原文和編輯時戳;都分不出來就寧可不寫,不用猜的。
4. **一次只動最少的行。** 打勾只改那一行,不會整份重寫。
